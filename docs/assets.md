# assets.md — арт, звук и анимации: куда класть и как ничего не сломать

Для художника, звукорежиссёра и всех, кто кладёт файлы в игру. Код трогать не нужно.
Таблицы ниже — копия манифестов в коде: `client/src/game/assetManifest.ts` (картинки) и
`client/src/audio/soundManifest.ts` (звуки). Если таблица и манифест расходятся — прав манифест,
напишите разработчику B.

---

## 1. Три правила

1. **Имя и размер — строго из таблиц.** Неизвестное имя или неверный размер — `npm test` красный, CI не даст слить. Игру это не сломает: неподходящий файл просто не попадёт в `main`.
2. **Один файл — один автор.** Только новые файлы. Чужой файл не перезаписывать — договориться с автором.
3. **Каждый набор записан в `docs/REFERENCES.md`**: кто сделал, чем, лицензия. ИИ-картинки — пометка «AI-GENERATED ART» в игре остаётся включённой (`SHOW_AI_ART_NOTICE` в `client/src/ui/aiNotice.ts`). **Никаких логотипов NASA, флагов и эмблем миссий** — ни нарисованных, ни сгенерированных.

Пока файла нет, игра рисует запасную картинку или играет запасной тон. **Отсутствие любого файла ничего не ломает** — художник никого не блокирует.

## 2. Куда класть

```
client/public/assets/
├─ sprites/        все картинки: и для поля (Phaser), и для экранов. Только .png, без подпапок
└─ audio/
   ├─ sfx/         эффекты: .ogg (+ .mp3 с тем же именем) или короткий .wav
   └─ music/       музыка, отбивки, эмбиент: .ogg + .mp3
art-src/           исходники: .aseprite, .psd, .kra, проекты BeepBox. В игру не попадают
```

## 3. Как проверить себя (5 минут)

1. Положить файл в нужную папку с именем из таблицы.
2. `npm test` — зелёный. Красный — прочитать сообщение: оно называет файл, ожидаемый и фактический размер (раздел 9).
3. `npm run dev` → http://localhost:5173/?dev=assets — картинка, анимация кадров, кнопка «проиграть звук» (страница появляется в задаче P0-B1 `phases.md`). Новый файл не виден — перезапустить `npm run dev`.
4. В игре: соло → Quick start. Файлы из таблиц «подключено» появляются сами. Файлы «v2» появятся, когда разработчик сделает задачу из колонки «Подключит».
5. Ветка `art/<что>` → PR → CI зелёный → squash. Не умеете git — отдайте файлы разработчику B, он закоммитит.

## 4. Картинки

### 4.1. Общие требования

- **PNG с прозрачностью.** Без фона.
- **Пиксель-арт 1:1.** Без сглаживания и размытых краёв. Уменьшать только «по ближайшему соседу» (nearest neighbor).
- **Кадры анимации — в один ряд** слева направо, без отступов. Файл = (ширина кадра × число кадров) × высота кадра. Пример: `astronaut.png` — 9 кадров 16×16 → файл 144×16.
- **Вид сверху с небольшим наклоном**, как текстура рельефа. Свет сверху-слева, тени вниз-вправо.
- **Палитра** — `product-logic.md`, раздел 12: Марс тёплый (ржавчина, охра, бордо), человек и техника холодные (голубой, белый), опасность — красный, награда — золотой, RED SIGNAL — малиновый. Персонаж должен читаться и на светлом грунте днём, и в круге фонаря ночью.
- **Вес** — не больше 256 КБ на файл.
- **ИИ-генерация:** результат уменьшить до точной сетки, почистить вручную, привести к палитре. На картинке — никакого текста, кроме штампа отчёта, и никаких логотипов.

## 5. Звук

### 5.1. Общие требования

- **Эффекты:** `.ogg` (лучше) и/или `.wav`, моно, 44,1 кГц. До 2 секунд, кроме петель. Без тишины в начале. Пик не выше −3 дБ. Не больше 400 КБ.
- **Петли** (`*_loop`): бесшовные, 1–4 с, `.ogg`.
- **Музыка:** `.ogg` + `.mp3` с тем же именем, не больше 3 МБ каждый. Три слоя вылазки — один темп, одна тональность, ровно одинаковая длина (`product-logic.md`, 11.1).
- **Громкость:** эффекты выровнять на слух между собой. Тревоги не делать громче остальных — игра сама приглушает музыку.
- **Имя файла = имя звука**, строчными буквами.

## 6. Анимации

- **Анимация = кадры в ряд.** Скорость задаёт код: ходьба ≈ 8 кадров/с, копание ≈ 5,5, дыхание ≈ 2. Нужна другая скорость — попросить разработчика B, а не рисовать лишние кадры.
- **Число кадров у подключённого файла менять нельзя** без B: игра и проверка ждут ровно столько.
- **Новая анимация** — это новое имя: B добавит строку в манифест и отрисовку. Сначала договориться, потом рисовать.
- **Анимации интерфейса** (штамп, набегающий счёт, титры актов) делает код на CSS — художнику хватит статичной картинки.
- **Частицы** (пыль, искры, лёд, обломки) — игра сама размножает и разгоняет кадр 8×8.

## 7. Тексты (для контент-команды)

- Все тексты игры — на английском в `client/src/i18n/en/*.ts`. Ключ слева не трогать, менять текст справа.
- Сюжет, радио, титры, разгадка — `story.ts` (ключи появятся в задаче A1).
- Плейсхолдеры в фигурных скобках (`{n}`, `{time}`) оставлять как есть.
- Одна строка на экран: радио — до 70 символов, задача — до 32, титр акта — до 24.

## 9. Частые ошибки

| Сообщение `npm test` или симптом | Что не так | Как исправить |
|---|---|---|
| `astronaut.png: expected 144×16 … got 128×16` | Кадров меньше, чем нужно (8 вместо 9) | Дорисовать кадр; кадры в один ряд без отступов |
| `… got 288×32` при ожидаемых `144×16` | Нарисовано в 2× | Экспортировать 1:1 |
| `unknown name` | Опечатка или заглавные буквы | Имя из таблицы, строчными |
| `right name, wrong folder` | Музыка в `sfx/` или эффект в `music/` | Переложить |
| `only .png belongs here` | Исходник в `sprites/` | Унести в `art-src/` |
| `… is over 256 KB` | Слишком тяжёлый файл | Палитра, PNG-8, без лишних метаданных |
| Белый прямоугольник вокруг спрайта | Нет прозрачности | Экспорт PNG с альфа-каналом |
| Мыльные края | Масштабирование со сглаживанием | Только nearest neighbor |
| Щелчок в петле | Обрез не по нулю | Обрезать по пересечению нуля, короткий кроссфейд |
| Файл не появился в `npm run dev` | Dev-сервер собрал список файлов при старте | Перезапустить `npm run dev` |

### Интерьер корабля

Исходники команды лежат в `assets/raw/` (`tileset.png`, `base_reference.png`). Игра использует
`client/public/assets/interior/atlas.webp` (предметы) и `tiles.webp` (тайлы пола и стен 64 px), WebP без потерь,
каждый файл до 1,4 МБ (`ASSET_LIMITS.interiorBytes`). Карта — `client/src/game/interior/data/base.tmj` (Tiled).
Как пересобрать — `tools/art/README.md`.
